# 화장품 인플루언서 시딩 퍼널 분석 프로젝트 기획서

## 1. 프로젝트 개요

**한 줄 정의**
유통 채널(올리브영/자사몰/스마트스토어/쿠팡 등)과 무관하게, 인플루언서 시딩 콘텐츠가 실제 구매까지 얼마나 이어졌는지, 어디서 이탈이 일어나는지, 그 원인이 무엇인지를 데이터로 진단하고 개선 액션까지 제안하는 마케팅 분석 도구.

**대상**
화장품 시딩·인플루언서 릴스 제작을 맡기는 마케팅팀

---

## 2. 문제 정의

인플루언서에게 제품을 시딩했을 때, 그것이 실제 구매로 이어지기까지는 많은 심리적 단계를 거칩니다. 사용자는 다음 요소들을 복합적으로 따집니다.

- 가격이 합리적인가
- 나에게 실제로 필요한가
- 인플루언서와 제품이 잘 어울리는가
- 효과가 진짜 있는가 (신뢰도)
- 너무 단기간에 많이 노출된 제품은 아닌가 (광고처럼 느껴지는 피로도)
- 사은품/구성 혜택이 좋은가

문제는, 사용자가 실제 구매 링크까지 들어가고도 구매하지 않는 경우가 많고, 기업 입장에서는 **어느 단계에서 사용자가 이탈했는지, 왜 이탈했는지 알 수 없다**는 점입니다.

**존재하는 데이터**: 인플루언서 목록, 상품 데이터
**부재한 데이터**: 노출 이후 사용자 행동(클릭, 체류, 이탈 지점), 이탈 원인

### 타겟 재정의: "올리브영 미입점 브랜드"가 아니다

당초 "올리브영에 입점 안 된 브랜드"를 타겟으로 생각했으나, 실제로 올리브영은 2,400여 개 뷰티&헬스 브랜드가 입점해 있어 대부분의 국내 화장품 브랜드가 이미 입점되어 있습니다. 따라서 타겟을 다음과 같이 재정의합니다.

> 유통 채널과 무관하게, **자사가 집행한 인플루언서 시딩 자체의 성과(어느 인플루언서가 얼마나 구매를 만들었는지)를 직접 추적하고 싶은 마케팅팀**

올리브영 같은 대형 유통사의 리테일미디어(성과형 광고)는 자기 플랫폼 내부 광고 클릭만 추적할 뿐, 브랜드가 외부(인스타그램·유튜브)에서 집행한 시딩 캠페인의 성과까지 브랜드사에 상세히 공유해주지 않습니다. 즉 올리브영 입점 여부와 무관하게 이 문제는 대부분의 브랜드가 공통으로 겪습니다.

## 3. 시장 배경

- K-뷰티는 '가성비'(1.0) → '성분 혁신'(2.0)을 지나 기술·웰니스·지속가능성을 축으로 한 'K-뷰티 3.0' 단계로 진화 중이며, 2025년 수출액 114억 달러로 세계 2위(프랑스에 이어 미국 추월), 2026년 1분기에는 전년 동기 대비 19% 성장한 31억 달러로 역대 분기 최고치 경신
- 2026년 소비자는 감각적 만족뿐 아니라 **데이터로 검증된 효능**을 중시하는 방향으로 이동 — "효과가 진짜 있는지"를 따지는 소비자 심리가 업계 전반의 화두가 됨
- 숏폼(릴스·쇼츠)이 단순 바이럴 콘텐츠에서 **검색→탐색→구매 퍼널의 입구**로 플랫폼 차원에서 재설계되는 중
- 메가 인플루언서보다 **미드티어·마이크로 인플루언서** 활용 비중이 커지는 추세 — 커뮤니티 리더 추천이 메가 인플루언서 대비 구매 전환율 3배 이상이라는 데이터도 존재
- 업계 리포트 자체에서 **"측정 인프라 정교화"**를 2026년 필수 과제로 명시 — 어트리뷰션/트래킹 도구의 필요성이 업계 공통 니즈로 확인됨

**시사점**: 인플루언서 수가 늘어날수록(마이크로 인플루언서 다수 활용) 개별 성과 관리는 더 어려워지고, 자동화된 추적 도구의 필요성은 오히려 커지는 방향과 일치함.

## 4. 핵심 로직: 측정 → 진단 → 처방

이 프로젝트의 핵심은 단순 트래킹이 아니라, 이탈 원인을 진단하고 실제 개선 액션까지 연결하는 루프입니다.

### 4-1. 측정 (퍼널 이벤트)

노출 → 클릭 → 랜딩 체류 → 장바구니 → 결제 시도 → 구매완료 단계별로 인플루언서·콘텐츠 단위 전환율을 집계합니다.

### 4-2. 진단 (이탈 원인 추정)

| 이탈 신호 조합 | 추정 원인 |
|---|---|
| 장바구니까지 갔다가 결제 페이지 이탈, 쿠폰 미적용 시 이탈률↑ | 가격 |
| 클릭은 하나 랜딩 체류시간 짧고 스크롤 없이 이탈 | 필요성/관심 부족 |
| 랜딩 체류는 긴데 리뷰 섹션에서 이탈 | 효과 신뢰도 부족 |
| 동일 인플루언서·상품 반복 노출될수록 CTR 하락 | 과다노출 피로도 |
| 옵션/구성 선택 페이지에서 이탈 | 사은품/구성 혜택 불만족 |

이탈 시점 마이크로 서베이(1문항 팝업)를 붙이면 "추정"을 "확인"으로 검증할 수 있습니다.

### 4-3. 처방 (원인 → 액션 제안)

| 진단된 원인 | 제안 액션 |
|---|---|
| 가격 이탈 | 경쟁 가격 비교 → 할인/번들 구성 제안, 가격 인하형 옵션 A/B 테스트 |
| 필요성 부족 | 콘텐츠 방향 수정 (사용 전/후 비교, 실사용 루틴 강조) |
| 신뢰도 부족 | 리뷰/성분 정보 노출 강화, 임상/어워드 인증 배지 추가 |
| 과다노출 피로도 | 해당 인플루언서 노출 빈도 하향, 인플루언서 로테이션 |
| 혜택 불만족 | 사은품 구성 변경, 경쟁사 대비 혜택 비교 데이터 제공 |

AI(LLM)를 활용해 이 진단·처방 과정을 자연어 리포트로 자동 생성하는 것도 v2 확장 방향으로 고려합니다.

## 5. 채널별 트래킹 제약과 대응 전략

숏폼(릴스·쇼츠)은 시딩의 핵심 포맷이지만, 두 플랫폼 모두 캡션·설명란 내 직접 클릭 트래킹이 막혀 있어 추적 방식을 채널별로 이원화해야 합니다.

| 포맷 | 캡션/설명란 링크 | 대안 |
|---|---|---|
| 인스타그램 릴스 | 클릭 불가 (텍스트로만 표시) | 스토리 링크 스티커, 프로필 바이오 링크 |
| 인스타그램 스토리 | 링크 스티커로 클릭 가능 | 그대로 UTM 사용 |
| 유튜브 롱폼 | 클릭 가능 | 그대로 UTM 사용 |
| 유튜브 쇼츠 | 클릭 불가 (2023.8 차단, 2026년 현재도 유지) | 유튜브 내부 링크만 허용 |

**대응 전략**

1. **구매 전환 집계는 쿠폰코드를 기본 수단으로 사용** — 인플루언서별 고유 할인코드를 영상 내 음성/자막으로 안내. 클릭 여부와 무관하게 결제 시점에 입력되므로 릴스·쇼츠에서도 확실하게 작동하고, 지연 전환(나중에 검색해서 구매)도 잡을 수 있음
2. **이탈 원인 진단은 링크 기반 트래픽에서 보조적으로** — 바이오 링크(링크인바이오 랜딩페이지로 콘텐츠별 세부 링크 구분) + 릴스 게시 직후 스토리 링크 스티커 연계 워크플로우로 일부 세션에서 퍼널 중간 단계를 확보
3. 롱폼(유튜브)과 숏폼(릴스·쇼츠)을 구분해 롱폼은 UTM 링크 방식, 숏폼은 쿠폰코드 방식으로 이원화

**한계**: 쿠폰코드는 "몇 건 팔렸는지"는 정확히 알려주지만 "어디서 이탈했는지"는 알려주지 못함. 링크는 이탈 지점을 보여주지만 릴스·쇼츠에서는 애초에 걸 수 없음 — 두 방식은 상호 보완적으로 병행해야 함.

## 6. MVP 기능 정의

| 기능 | 내용 | 우선순위 |
|---|---|---|
| ① 쿠폰코드/링크 발급기 | 인플루언서·콘텐츠별 고유 할인코드 + (가능한 채널에서는) UTM 딥링크 자동 생성 | MVP 필수 |
| ② 퍼널 대시보드 | 인플루언서별 코드 사용·클릭→랜딩→장바구니→구매 전환율 비교 | MVP 필수 |
| ③ 이탈 원인 태깅 | 이탈 시점 팝업 + 행동 신호 기반 원인 자동 분류 | v2 |
| ④ AI 인사이트 리포트 | 진단 결과를 자연어 요약 + 액션 제안으로 자동 생성 | v2 |

## 7. 데이터 모델 (최소 스키마)

```
influencers: influencer_id, name, follower_count, category
contents:    content_id, influencer_id, product_id, upload_date, platform, coupon_code
events:      event_id, content_id, session_id, event_type(click/view/cart/purchase), timestamp
products:    product_id, name, price, channel(올리브영/자사몰/스마트스토어), bundle_option
orders:      order_id, session_id, product_id, amount, coupon_code, timestamp
```

`content_id`가 UTM 파라미터 및 `coupon_code`와 1:1 매칭되어야 세션/주문이 어느 인플루언서에서 왔는지 끊기지 않습니다.

## 8. 기술 스택 (개인 프로젝트 규모)

- **링크/코드 발급**: FastAPI 또는 Node.js — UTM 파라미터 자동 부착 및 쿠폰코드 자동 채번, 클릭 시 리다이렉트하며 이벤트 로깅
- **이벤트 수집**: 자사몰은 GA4 연동 또는 직접 스크립트 삽입 / 외부 플랫폼(올리브영·쿠팡 등)은 클릭 단계까지만 자체 로깅하고 이후는 쿠폰코드 사용 데이터로 대체
- **DB**: PostgreSQL
- **대시보드**: 인플루언서별 전환 퍼널 시각화 위젯

### 현실적 한계와 우회

- 올리브영·쿠팡 등 외부 플랫폼은 구매 데이터를 브랜드사에 제공하지 않음 → 쿠폰코드 사용 데이터로 대체, 또는 자사몰/스마트스토어 판매 브랜드를 우선 타겟으로 설정
- 완전한 인과 어트리뷰션은 불가능 → "정확한 인과관계"보다 "인플루언서 간 상대 비교"에 초점

## 9. 프로젝트 차별점

쿠폰코드나 UTM 링크를 활용한 성과 추적 자체는 쉬인·테무를 비롯한 어필리에이트 마케팅 업계에서 이미 널리 쓰이는 방식으로, 새로운 기법은 아닙니다. 이 프로젝트의 차별점은 추적 수단이 아니라 **추적 이후의 처리 방식**에 있습니다.

| | 기존 어필리에이트 방식 | 본 프로젝트 |
|---|---|---|
| 코드/링크 활용 목적 | 판매 정산, 수수료 계산 | 퍼널 진단의 입력 데이터 |
| 산출물 | 인플루언서별 매출 집계표 | 이탈 원인 분류 + 개선 액션 제안 |
| 분석 깊이 | 단순 집계 | 진단(원인 추정) → 처방(액션 제안)까지 연결된 루프 |

쿠폰코드/링크는 여러 채널에서 안정적으로 데이터를 수집하기 위한 수단일 뿐이며, 핵심 가치는 "진단-처방 로직"과 이를 자연어 리포트로 자동화하는 AI 인사이트 생성 기능에 있습니다.
