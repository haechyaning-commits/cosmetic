# 인플루언서-제품 매칭 스코어링 서비스 기획서

## 0. 문서 개요
본 문서는 화장품 인플루언서 시딩 마케팅의 어려움을 데이터로 해결하는 프로젝트의 상세 기획서입니다. 전체 비전(시딩→구매 퍼널 추적)에서 출발했으나, 보유 데이터와 검증 가능성을 고려해 **1차 MVP를 "인플루언서-제품 매칭 스코어링"으로 확정**하고, 퍼널 추적은 2차 확장 비전으로 재배치했습니다.

---
## 1. 프로젝트 개요
**한 줄 정의**
인플루언서 목록과 상품 데이터를 입력하면, 어떤 인플루언서에게 어떤 제품을 시딩해야 가장 잘 맞는지를 콘텐츠 맥락 기반으로 자동 스코어링해주는 도구.

**대상**
화장품 시딩·인플루언서 릴스 제작을 맡기는 마케팅팀

**보유 데이터 (그대로 활용 가능)**
- 인플루언서 목록: 이름, 팔로워 수, 카테고리/니치, 최근 콘텐츠 캡션 등
- 상품 데이터: 상품명, 가격, 카테고리, 성분/효능 설명 등

---
## 2. 문제 정의
### 2-1. 왜 이 문제가 남아있는가
인플루언서 마케팅 시장에는 이미 Modash, InfluData, Aspire 같은 발굴·매칭 툴이 존재합니다. 이 툴들은 팔로워 수, 참여율, 오디언스 인구통계(연령·성별·지역) 등 **50개 이상의 정형 필터**로 대량의 후보를 자동으로 좁혀줍니다.

하지만 뷰티 업계 실전 가이드에서도 명확히 짚는 한계가 있습니다 — 자동화 도구가 의심 계정을 걸러줄 수는 있지만, **최종 판단은 콘텐츠와 댓글의 맥락이 결정합니다.** 예를 들어 콜라겐 파우더는 "건강" 니치로 분류되지만, 실제로는 피부 탄력에도 관여하는 성분이라 스킨케어 니치 크리에이터에게도 유효합니다. 이런 **인접 니치 매칭**은 팔로워 수·카테고리 라벨 같은 정형 데이터만으로는 발견되지 않고, 콘텐츠의 실제 언어(캡션, 후기 표현)를 이해해야 잡히는 지점입니다.

### 2-2. 이 프로젝트가 채우는 지점
| | 기존 매칭 툴 (Modash 등) | 본 프로젝트 |
|---|---|---|
| 매칭 기준 | 정형 필터: 팔로워 수, 인구통계, 카테고리 라벨 | 정형 필터 + 콘텐츠 텍스트의 의미적 유사도 |
| 인접 니치 발견 | 안 됨 (카테고리 라벨이 다르면 매칭 안 됨) | 됨 (텍스트 임베딩으로 의미가 겹치면 매칭) |
| 검증 가능성 | 대규모 실사용 데이터 필요 | 보유 데이터(인플루언서 목록+상품 데이터)만으로 바로 프로토타입 가능 |

## 3. 시장 배경
- 인플루언서 마케팅 업계에서 뷰티 부문은 캠페인 활용 비중이 가장 높은 산업군으로 나타납니다.
- 2026년 인플루언서 마케팅은 메가 인플루언서보다 미드티어·마이크로 인플루언서 활용 비중이 커지는 추세이며, 인플루언서 수가 늘어날수록 개별 매칭 판단에 드는 리소스도 커집니다.
- AI 도구가 인플루언서 마케팅에서 아웃리치 자동화, 검증, ROI 측정까지 처리하는 흐름으로 진화하고 있으나, 국내외 툴 모두 "후보 필터링"에 강점이 있을 뿐 "콘텐츠 의미 기반 매칭"은 상대적으로 미성숙한 영역입니다.
- 성공 사례들을 보면, 제품-인플루언서 매칭은 핵심 니치를 넘어 성분·효능이 걸치는 인접 니치까지 확장할 때 콘텐츠 다양성과 신선도가 높아진다는 점이 강조됩니다 (예: 콜라겐 파우더 → 건강 니치 + 스킨케어 니치).

**시사점**: "정형 필터는 툴이 대신해준다"는 인식이 업계에 이미 자리 잡은 상태이기 때문에, 차별화 지점은 반드시 "그 다음" — 즉 콘텐츠의 의미를 읽는 계층에 있어야 합니다.

## 4. 핵심 로직: 매칭 스코어링 알고리즘
### 4-1. 전체 구조
매칭 스코어는 **정형 필터(1차 통과/탈락)** 와 **의미 기반 유사도(2차 순위화)** 를 결합한 2단계 구조입니다.

```
[인플루언서 데이터] ──┐
                      ├──> 1단계: 정형 필터 ──> 후보군 압축
[상품 데이터]     ──┘
후보군 ──> 2단계: 의미 기반 매칭(임베딩 유사도) ──> 최종 스코어 ──> 랭킹 리스트
```

### 4-2. 1단계 — 정형 필터 (Hard Filter)
명백히 안 맞는 조합을 먼저 제거합니다.
| 필터 항목 | 판단 기준 |
|---|---|
| 팔로워 규모대 | 캠페인 목표(인지도/전환)에 맞는 인플루언서 티어(나노/마이크로/미드/메가)인지 |
| 가격대 적합성 | 인플루언서의 평균 협찬 단가 수준과 상품 가격대가 크게 어긋나지 않는지 |
| 오디언스 인구통계 | 상품의 타겟 연령·성별과 팔로워 구성이 겹치는지 |
| 협찬 이력 충돌 | 최근 경쟁 브랜드 협찬 이력이 있는지 (있으면 제외 또는 감점) |

### 4-3. 2단계 — 의미 기반 매칭 (Semantic Match)
**여기가 핵심 차별점입니다.**
1. 인플루언서 텍스트 프로필: 최근 콘텐츠 캡션들 + 니치 키워드 + 댓글 관심사 키워드를 합침
2. 상품 텍스트 프로필: 상품명 + 카테고리 + 핵심 성분 + 효능 + 사용 시나리오를 합침
3. 각 텍스트를 임베딩으로 벡터화
4. 두 벡터 간 코사인 유사도를 `semantic_score`(0~1)로 산출

### 4-4. 최종 스코어 산출
```
final_score = (semantic_score × w1) + (engagement_rate_normalized × w2) + (audience_fit_score × w3)
```
- `w1, w2, w3`는 캠페인 목표에 따라 마케터가 슬라이더로 조정
- 매출 전환형 → w1(콘텐츠 적합성) ↑ / 인지도 확산형 → w2(참여율) ↑

### 4-5. 결과물
상품 하나를 입력 → 매칭 상위 인플루언서 N명을 스코어 순으로 리스트업 + **매칭 근거**(어떤 콘텐츠/키워드가 유사도를 높였는지).

## 5. MVP 기능 정의
| 기능 | 내용 | 우선순위 |
|---|---|---|
| ① 데이터 업로드/정리 | 인플루언서·상품 CSV/엑셀 업로드 및 텍스트 필드 정제 | MVP 필수 |
| ② 정형 필터링 | 팔로워 규모, 가격대, 인구통계 기준 1차 필터 | MVP 필수 |
| ③ 의미 기반 매칭 엔진 | 임베딩 기반 유사도 계산 및 스코어 산출 | MVP 필수 |
| ④ 매칭 결과 대시보드 | 상품별 상위 인플루언서 랭킹 + 매칭 근거 | MVP 필수 |
| ⑤ 가중치 조정 UI | 정형/의미 가중치 슬라이더 | v1.5 |
| ⑥ 매칭 이력 관리 | 과거 매칭·실제 시딩 결과 기록 | v2 |

## 6. 데이터 모델
```
influencers:
  influencer_id, name, follower_count, niche_category,
  recent_captions (text), comment_keywords (text),
  engagement_rate, avg_sponsorship_price, audience_age_group, audience_gender_ratio
products:
  product_id, name, category, price,
  ingredients (text), efficacy_description (text), usage_scenario (text)
match_results:
  match_id, influencer_id, product_id,
  semantic_score, engagement_score, audience_fit_score, final_score, created_at
seeding_history (v2):
  history_id, influencer_id, product_id, match_id, actual_posted (bool), performance_note
```

## 7. 기술 스택
- **백엔드**: FastAPI (Python)
- **임베딩**: OpenAI/Voyage 계열 임베딩 API 또는 한국어 특화 오픈소스(sentence-transformers 계열)
- **유사도**: numpy 코사인 유사도, 필요 시 FAISS
- **DB**: PostgreSQL (pgvector 확장 시 DB 레벨 벡터 검색)
- **프론트**: 랭킹 테이블 + 필터/가중치 조정 UI

---
## 8. 검증 방법
- 알려진 매칭 사례(콜라겐 파우더 → 건강+스킨케어 이중 매칭)를 테스트 케이스로, 알고리즘이 인접 니치를 스스로 찾는지 확인
- 마케터 직관 답변 vs 알고리즘 결과 정성 비교
- 정형 필터만 vs 의미 매칭 추가 시 랭킹 차이 비교 — "라벨은 다르지만 의미상 맞는" 인플루언서 발굴 검증

---
## 9. 프로젝트 차별점 (요약)
기존 툴은 정형 데이터 필터링(업계 표준)에 강점. 본 프로젝트는 여기에 **콘텐츠 텍스트의 의미를 이해하는 계층**을 더해, 카테고리 라벨이 달라도 의미가 겹치는 인접 니치 인플루언서를 발굴.

---
## 10. 향후 확장 비전 (2차 단계)
1. **시딩 결과 피드백 루프**: 추천 인플루언서에게 실제 시딩 후 결과를 `seeding_history`에 기록해 스코어링 보정
2. **시딩→구매 퍼널 추적**: 게시 이후 쿠폰코드·UTM 기반 전환·이탈 진단 (→ `phase2-funnel/`에 프로토타입 구현됨)
3. **인플루언서 발굴·검증 통합**: 참여율·가짜 팔로워·협찬 충돌 자동 검증

> 부록(채널별 트래킹 제약, 진단-처방 로직, 대기업 현황)은 2차 확장용 설계 메모로, `docs/phase2-funnel-기획서.md` 및 `phase2-funnel/` 구현에 반영되어 있습니다.
