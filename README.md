# 화장품 인플루언서-제품 매칭 스코어링

인플루언서 목록과 상품 데이터를 입력하면, **어떤 인플루언서에게 어떤 제품을 시딩해야 가장 잘 맞는지**를 콘텐츠 맥락(텍스트 임베딩) 기반으로 자동 스코어링하는 도구.

## 핵심 아이디어
기존 매칭 툴(Modash 등)은 팔로워 수·인구통계 같은 **정형 필터**가 강점이지만, 카테고리 라벨이 다르면 놓치는 **인접 니치**를 못 잡는다. 이 프로젝트는 여기에 **콘텐츠 텍스트의 의미 유사도**를 더해, "라벨은 다르지만 의미가 겹치는" 인플루언서를 발굴한다.

> 예: 콜라겐 파우더(건강 니치 상품)에 대해, '건강' 라벨 인플루언서뿐 아니라 캡션에 "피부 탄력·속당김"이 반복되는 **스킨케어 인플루언서도 상위로** 올라온다. 반대로 같은 '건강' 라벨이라도 운동·단백질 위주면 낮게.

## 스코어 구성
```
final = w1·의미유사도 + w2·참여율 + w3·오디언스핏     (w1+w2+w3 = 1)
```
- 1단계 **정형 필터**: 경쟁 브랜드 협찬 충돌·인구통계 불일치 후보 제외
- 2단계 **의미 매칭**: 인플루언서 텍스트 ↔ 상품 텍스트 임베딩 코사인 유사도
- 가중치 슬라이더/프리셋(전환형·인지도형)으로 캠페인 목표에 맞춰 재정렬

## 실행
```bash
pip install -r requirements.txt
python scripts/seed_matching.py       # 샘플 데이터 (matching.db)
uvicorn app.main:app --reload         # http://127.0.0.1:8000
```
- `/product/{id}` — 상품별 인플루언서 매칭 랭킹 + 매칭 근거 + 가중치/토글

### 임베딩 백엔드 (교체형)
`app/embeddings.py`가 키 유무로 자동 선택. 실제 의미 매칭은 API 백엔드 권장.
```bash
export OPENAI_API_KEY=...    # text-embedding-3-small
# 또는
export VOYAGE_API_KEY=...    # voyage-3 (한국어 포함 다국어)
```
키가 없으면 `hashing`(오프라인 폴백, 렉시컬 위주)으로 파이프라인은 돌아가되 의미 인접성은 약함.

### 구조
```
app/
  db.py          스키마·연결 (SQLite, PostgreSQL 호환)
  embeddings.py  교체형 임베딩 백엔드(openai/voyage/hashing) + 캐시
  scoring.py     정형 필터 + 하위점수 + 최종 스코어 + 매칭 근거
  main.py        FastAPI 라우트 + 대시보드
  templates/ static/
scripts/seed_matching.py   샘플 데이터(콜라겐 인접 니치 검증 케이스 내장)
```

## 로드맵
1. **MVP (현재)**: 정형 필터 + 의미 매칭 + 랭킹 대시보드 + 가중치 슬라이더
2. 데이터 업로드(CSV) · 매칭 이력 저장
3. 시딩 결과 피드백 루프로 스코어 보정
4. **시딩→구매 퍼널 추적** (프로토타입: [`phase2-funnel/`](phase2-funnel/))

---
### phase2-funnel/
1차 비전이었던 시딩→구매 퍼널 추적 대시보드의 프로토타입. 매칭 이후 게시된 콘텐츠의 전환·이탈을 쿠폰코드·UTM으로 진단. 2차 확장 자산으로 보존.
