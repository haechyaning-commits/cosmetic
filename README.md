# 화장품 인플루언서 시딩 퍼널 분석

유통 채널(올리브영/자사몰/스마트스토어/쿠팡 등)과 무관하게, 자사가 집행한 **인플루언서 시딩 콘텐츠가 실제 구매까지 얼마나 이어졌는지**를 인플루언서·콘텐츠 단위로 추적하고, 인플루언서 간 상대 성과를 비교하는 마케팅 분석 도구.

## 핵심 아이디어
- 쿠폰코드/UTM 링크를 **추적 수단**으로 쓰되, 가치는 그 이후의 **진단(이탈 원인) → 처방(개선 액션)** 루프에 있다.
- 릴스·쇼츠는 링크가 막혀 있고 외부몰은 구매 데이터를 안 주므로, 퍼널을 **쿠폰 트랙(전 채널 구매) / 링크 트랙(자사몰 전체 퍼널)** 2개로 분리해 측정한다.

## 로드맵
1. **MVP**: 쿠폰/링크 발급기 + 클릭·쿠폰 트래킹 + 인플루언서 비교 대시보드 ← 현재
2. 이벤트 수집 파이프라인 + 자사몰 GA4 연동
3. 이탈 원인 태깅
4. AI 인사이트 리포트 자동 생성
